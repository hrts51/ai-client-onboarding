Project Overview

This project automates the complete client onboarding process using AI-powered workflow automation. When a client submits an onboarding form, the system processes their information using a locally hosted Mistral 7B language model, stores the data in Google Sheets, sends a personalized welcome email, and notifies the internal team on Slack — all automatically, in under 30 seconds.

The key innovation is replacing expensive cloud AI APIs (like OpenAI) with a locally hosted, fine-tuned Mistral model running on consumer hardware, reducing recurring AI processing costs to zero.

Installation

# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/ai-client-onboarding.git
cd ai-client-onboarding

# 2. Pull Mistral 7B (4.4GB download)
ollama pull mistral

# 3. Start n8n via Docker
cd docker
docker compose up -d

# 4. Open n8n in browser
# http://localhost:5678

# 5. Import the workflow
# n8n → Add workflow → Import from file
# Select: n8n-workflows/onboarding-workflow-googleform.json

Test the System

n8n Workflow

The workflow consists of 7 nodes connected in sequence:

1️⃣

Google Form Trigger

Polls the Google Sheet linked to the form every minute. Fires when a new response is detected.

2️⃣

Extract & Validate Data

JavaScript node that maps form fields to standard data structure and validates required fields.

3️⃣

Mistral AI Processing

HTTP request to Ollama API at host.docker.internal:11434. Sends client data, receives structured AI analysis.

4️⃣

Merge AI Analysis

Combines client data with Mistral's response. Generates unique client ID (CLT-XXXXXXXX).

5️⃣

Save to Google Sheets

Appends a new row with all 13 fields including AI analysis to the client onboarding spreadsheet.

6️⃣

Email Client

Sends a branded HTML welcome email to the client with their reference ID and submission summary.

7️⃣

Slack Notification

Posts full client details and AI analysis to #onboarding-alerts channel for immediate team review.

AI Model — Mistral 7B

The system uses Mistral 7B Instruct v0.2, a 7-billion parameter open-source language model running locally via Ollama. It is loaded in 4-bit quantized format (Q4_K_M), which reduces memory usage to ~4.4GB — fitting comfortably in a 6GB VRAM GPU like the RTX 3060.

LoRA Fine-tuning

The base Mistral model is fine-tuned using LoRA (Low-Rank Adaptation) — a parameter-efficient technique that trains only a small set of adapter weights rather than the entire model, making it feasible on consumer GPUs.

Why Fine-tune?

🎯

Domain Specific

Teaches Mistral the specific format and style of onboarding analysis for professional services.

⚡

Faster Responses

Fine-tuned model needs less prompting to produce correctly structured output.

💡

Consistent Output

Base model responses vary; fine-tuned model follows the exact analysis format every time.

Training Configuration

ParameterValueReason
Base ModelMistral 7B Instruct v0.2Best open-source instruct model at 7B scale
Quantization4-bit (NF4)Fits in 6GB VRAM
LoRA Rank (r)16Balance between capacity and memory
LoRA Alpha32Standard 2x rank scaling
Epochs3Sufficient for small dataset
Learning Rate2e-4Standard for LoRA fine-tuning
Batch Size1 + grad accum 4Effective batch of 4 within VRAM limit

Run Fine-tuning

# Activate the Python 3.11 virtual environment
cd fine-tuning
.\venv\Scripts\Activate.ps1

# Start training (uses RTX 3060 GPU automatically)
python train.py

# After training, serve in Ollama
ollama create onboarding-mistral -f output/mistral-onboarding-lora/Modelfile
ollama run onboarding-mistral
